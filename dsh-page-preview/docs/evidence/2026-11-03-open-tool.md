# 手动 open 的静态原文件链路

`page_preview_open` 已接通锁定 DSH ToolRuntime→调用者身份→共同配置/应用画像→目标解析→Planner→独立 Runner→原文件 static 服务。本文说明静态路径；已有服务见 existing-server.md，已批准项目命令见 project-command.md，Vue 隔离和产品 Client 仍按进度表开发。

## 行为与边界

- 使用不可变 session.header.cwd 和会话 ID。缺少明确调用者/工作区时不分配资源，不从 Host cwd 或工具参数猜测身份。
- Host 与 Runner 共用 loadWorkspaceProjects。无配置 HTML 应用使用相同的稳定检测 ID；Runner 重读唯一配置来源并核对指纹。配置应用拥有其中普通 HTML 子目录，不再产生重复应用；独立包/构建配置仍可形成嵌套应用候选。
- SDK 的 target.oneOf 从 canonical Zod 选择器结构投影，不重复维护五套字段。SDK 只支持 boolean additionalProperties，非空文本和路由映射字符串值仍由原 canonical 边界校验；结构不支持时明确失败。
- 省略 target 时返回候选，即使只有一个也不假定与当前任务相关。省略 projectId 遇到歧义不取第一个。默认最多给三个候选，并说明总数；调用者可用明确 ID/路径缩小范围。
- scope/strategy/scenario/viewport/requirements 进入原 Planner。已有/默认 mock-only 不被请求清空；不支持的视口、初始化、组件或未实现适配器明确拒绝。执行项没有用户批准时不运行，也不自动创建批准。
- 只有实现的适配器进入公开注册表；其余骨架仍保留开发，不在生产路径调用 notImplemented 后吞掉错误。当前只有 static，可显示已有原 HTML/JS；不为不支持框架生成替代页面。
- 同属会话、相同完整计划复用原 previewId。计划变化由 Runner 先清理旧目标再启动新目标，本次 open 返回 preview_restarted 说明；它是操作结果提示，不冒充 HMR。异属会话的活动预览返回 busy。
- Runner 接受后默认等待到就绪/降级/终态或 15 秒（可取消）：计划配置了目标断言时 reachable 继续等待 ready/degraded/期限失败；无断言计划的就绪上限即 reachable，到 reachable 即返回（§805 观察模式）。Root 初始化和 IPC 请求另有默认各 10 秒截止时间，Node 版本检查最多 3 秒。取消停止等待，已受理预览继续由同一 status/stop 找回和显式清理。
- 工具 render 输出紧凑文本摘要（状态行 + 预览/候选/占用者 + 诊断），不回显整段 JSON；结构化值仍由 schema 承载。Host 投影把每条诊断盖上来源 previewId；hint 一律为 Agent 可执行动作（调用工具、改配置/文件、请用户操作），不写"Inspect the local browser"类指示。
- 只返回实际快照和能力缺口；默认不带完整计划，status 指定 previewId、detail:true 可取。未知目标挂载和源码对应关系仍为 unverified。页面可达不等于 ready，也不等于 Client 已自动显示页面。

## 验证

测试使用临时工作区和独立 SDK Context，无真实模型/后端或用户 DSH profile 操作。覆盖真实 public open、无配置 ID、重复打开、有序切换、busy、结构/语义校验、候选预算、缺失目标、损坏配置/清单、requirements 保留、执行授权拒绝，以及取消后找回/停止。

等待窗口的两个回归刻意模拟状态投影延迟，受理和资源仍由真实 Runner 管理；不把它们作为真实慢构建的验收。运行态 PID/端口/账本与停止失败路径另有真实基础设施测试。
